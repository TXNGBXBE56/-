รายละเอียดการพัฒนาเว็บไซต์

ข้อมูลความเป็นมาและรูปแบบการจัดทำโครงงาน

🎮 ระบบเกมการศึกษา (Gamification)

เพื่อเพิ่มความสนุกสนานและลดความน่าเบื่อในการเรียนออนไลน์ เว็บไซต์ของเราจึงได้ออกแบบและพัฒนากิจกรรมเสริมการเรียนรู้ ดังนี้:

  • เกมท้ายบทเรียน: มีมินิเกมหรือแบบทดสอบเชิงเกมมิฟิเคชันจำนวน 1 เกมต่อ 1 บทเรียน รวมทั้งหมด 10 บท
  • วัตถุประสงค์: เพื่อให้ผู้เรียนได้ทบทวนความเข้าใจ วัดผลตนเอง และเสริมสร้างแรงจูงใจในการศึกษาเนื้อหารายวิชาระบบปฏิบัติการคอมพิวเตอร์

📅 ข้อมูลการจัดทำและเผยแพร่

เว็บไซต์นี้เป็นส่วนหนึ่งของโครงงานระดับประกาศนียบัตรวิชาชีพ (ปวช.3) แผนกเทคโนโลยีธุรกิจดิจิทัล รายละเอียดสำคัญมีดังนี้:

  • ระยะเวลาพัฒนา: พัฒนาขึ้นในช่วงปีการศึกษา 2569
  • วันที่เผยแพร่ระบบ: เปิดให้บริการและเผยแพร่ออนไลน์อย่างเป็นทางการในวันที่ 24 มกราคม 2570
  • เทคโนโลยีที่ใช้: พัฒนาด้วยภาษา HTML, CSS และ JavaScript พร้อมระบบหน้าจอโหลดดิ้งและเอฟเฟกต์ตอบสนองที่ทันสมัย
