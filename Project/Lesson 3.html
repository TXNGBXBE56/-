3.1 · PROPRIETARY

ระบบปฏิบัติการมาตรฐานปิด (Proprietary OS)

เป็นระบบปฏิบัติการที่มีเจ้าของสิทธิ์หรือลิขสิทธิ์ชัดเจน ผู้ใช้งานต้องซื้อหรือได้รับอนุญาต (License) ก่อนใช้งาน โค้ดโปรแกรมถูกปิดเป็นความลับ

การสนับสนุนมีการซัพพอร์ตอย่างเป็นทางการจากบริษัทผู้ผลิต มีความเสถียรสูง
ข้อจำกัดมีค่าใช้จ่ายสูงและไม่สามารถแก้ไขซอร์สโค้ดเองได้ เช่น Windows, macOS
จุดเด่น: ใช้งานง่าย มีซอฟต์แวร์รองรับหลากหลาย และเหมาะกับผู้ใช้ทั่วไปจนถึงระดับองค์กร
🔓
3.2 · OPEN SOURCE

ระบบปฏิบัติการมาตรฐานเปิด (Open Source OS)

เป็นระบบปฏิบัติการที่เปิดเผยซอร์สโค้ด (Source Code) อนุญาตให้ผู้ใช้ทั่วไปสามารถนำไปศึกษา พัฒนาต่อยอด หรือแจกจ่ายได้โดยไม่มีค่าใช้จ่ายลิขสิทธิ์

ความยืดหยุ่นปรับแต่งระบบได้อิสระตามความต้องการ มีความปลอดภัยสูง
ตัวอย่างระบบปฏิบัติการ Linux, Ubuntu, Fedora และ Debian
จุดเด่น: ประหยัดค่าใช้จ่าย ปลอดภัย และมีชุมชนนักพัฒนาคอยช่วยเหลืออัปเดตอย่างต่อเนื่อง
⚙️
3.3 · INSTALLATION

ขั้นตอนการติดตั้งระบบปฏิบัติการเบื้องต้น

กระบวนการนำระบบปฏิบัติการลงสู่เครื่องคอมพิวเตอร์เพื่อให้พร้อมใช้งาน มีขั้นตอนสำคัญดังนี้

  • 1. เตรียมสื่อติดตั้ง: จัดทำ USB Boot หรือแผ่นติดตั้งระบบปฏิบัติการที่ต้องการ
  • 2. ตั้งค่า BIOS/UEFI: ปรับลำดับการบูตเครื่องให้เริ่มจาก USB หรือแผ่นติดตั้ง
  • 3. แบ่งพาร์ทิชัน (Partition): กำหนดพื้นที่จัดเก็บข้อมูลบนฮาร์ดดิสก์หรือ SSD
  • 4. ติดตั้งระบบ: คัดลอกไฟล์ระบบ ตั้งค่าภาษา ผู้ใช้งาน และรหัสผ่าน
  • 5. ติดตั้งไดรเวอร์: ติดตั้งโปรแกรมควบคุมอุปกรณ์ฮาร์ดแวร์เพื่อให้ทำงานสมบูรณ์
