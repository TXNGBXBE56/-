01 · TOPICS

บทนี้เราจะ
เรียนรู้อะไร?

02 · PROCESS MANAGEMENT

ระบบปฏิบัติการ
จัดการงานอย่างไร?

ระบบปฏิบัติการเป็นซอฟต์แวร์ที่ทำหน้าที่เป็นตัวกลางระหว่างผู้ใช้กับฮาร์ดแวร์ ช่วยจัดสรรทรัพยากรและจัดการการทำงานของโปรแกรม

01
🟡

Ready State

สถานะพร้อมทำงาน รอให้ระบบปฏิบัติการจัดสรร CPU ให้

02
⚙️

Running State

สถานะที่โปรเซสกำลังใช้ CPU เพื่อประมวลผล

03
⏳

Blocked State

สถานะที่หยุดรอเหตุการณ์ เช่น รอข้อมูลจากอุปกรณ์รับส่งข้อมูล

04
🔒

Deadlocked State

ตามเนื้อหาบทเรียน หมายถึงการรอเหตุการณ์ที่ไม่เกิดขึ้น ทำให้โปรแกรมค้าง

โปรแกรมที่กำลังทำงานอยู่เรียกว่า โปรเซส (Process) ซึ่งระบบปฏิบัติการต้องควบคุมและจัดสรรเวลา CPU ให้เหมาะสม

03 · OS FUNCTIONS

หน้าที่สำคัญของ
ระบบปฏิบัติการ

🖥️

ควบคุมฮาร์ดแวร์

จัดการฮาร์ดดิสก์ แป้นพิมพ์ จอภาพ และอุปกรณ์ต่อพ่วง

⚡

จัดสรร CPU

จัดลำดับและแบ่งเวลาให้โปรเซสต่าง ๆ ทำงาน

🧠

จัดการหน่วยความจำ

จัดสรรพื้นที่หน่วยความจำให้โปรแกรมตามความจำเป็น

🔐

จัดการไฟล์และความปลอดภัย

ดูแลการจัดเก็บไฟล์และควบคุมการเข้าถึงข้อมูล

04 · BOOT PROCESS

ก่อนคอมพิวเตอร์
พร้อมใช้งาน

🚀
01เปิดเครื่องและเริ่มกระบวนการเริ่มระบบ (Boot)
02Firmware/BIOS ใน ROM ช่วยตรวจสอบความพร้อมของฮาร์ดแวร์
03ระบบเริ่มโหลดระบบปฏิบัติการเข้าสู่หน่วยความจำ
04ระบบปฏิบัติการเริ่มจัดการอุปกรณ์ หน่วยความจำ และโปรเซส
05ผู้ใช้สามารถเข้าสู่ระบบและเรียกใช้โปรแกรมได้
05 · OS TYPES

ระบบปฏิบัติการ
มีหลายประเภท

แต่ละประเภทออกแบบให้เหมาะกับลักษณะอุปกรณ์และจำนวนผู้ใช้งาน

01

Stand-Alone OS

ระบบปฏิบัติการที่ใช้งานบนคอมพิวเตอร์ส่วนบุคคลเป็นหลัก เช่น ใช้ทำงาน ดูหนัง และฟังเพลง

02

Network OS

รองรับการใช้งานร่วมกันของผู้ใช้หลายคนในเครือข่าย เช่น ระบบในองค์กรและเซิร์ฟเวอร์

03

Embedded OS

ระบบปฏิบัติการสำหรับอุปกรณ์เฉพาะทางหรืออุปกรณ์ขนาดเล็กตามลักษณะการใช้งาน

LESSON 02
🛠️
2.1

หน้าที่และความสำคัญของระบบปฏิบัติการ

ระบบปฏิบัติการช่วยให้ผู้ใช้สั่งงานคอมพิวเตอร์ได้สะดวก และดูแลการทำงานเบื้องหลังหลายด้าน

ควบคุมอุปกรณ์จัดการฮาร์ดดิสก์ แป้นพิมพ์ จอภาพ และอุปกรณ์ต่อพ่วง
ทำงานร่วมกับ Firmware/BIOSตรวจสอบความพร้อมของฮาร์ดแวร์ก่อนเริ่มระบบ
จัดการ CPU และหน่วยความจำจัดลำดับงานและจัดสรรทรัพยากรให้โปรแกรม
จัดการข้อมูลจัดเก็บไฟล์ลงในหน่วยเก็บข้อมูลสำรอง (Secondary Storage)
ดูแลความปลอดภัยช่วยควบคุมสิทธิ์การใช้งานและปกป้องข้อมูล
📚
2.2 · STANDARDS

มาตรฐานและลักษณะของระบบปฏิบัติการ

  • Proprietary: ซอฟต์แวร์กรรมสิทธิ์ที่การใช้งานและการติดตั้งอยู่ภายใต้เงื่อนไขของเจ้าของสิทธิ์ ซึ่งอาจต้องซื้อใบอนุญาต
  • DOS (Disk Operating System): ระบบปฏิบัติการที่ใช้งานผ่านบรรทัดคำสั่งเป็นหลัก ไม่มีส่วนติดต่อแบบกราฟิกในลักษณะ Windows สมัยใหม่ และมีการใช้งานบน IBM PC ตั้งแต่ปี ค.ศ. 1981 (พ.ศ. 2524)

ที่ควรรู้

ไล่ดูพัฒนาการของ Windows จากส่วนติดต่อผู้ใช้แบบกราฟิกไปสู่เครื่องมือทำงานและ AI

🖱️

Windows 95 / 98 / ME

GUI ใช้งานง่ายขึ้น รองรับ Multitasking มัลติมีเดีย และเครือข่ายภายในบ้าน

🌈

Windows XP

เน้นประสบการณ์ใช้งาน หน้าตาน่าใช้ ติดตั้งฮาร์ดแวร์และเครือข่ายสะดวก พร้อม Windows Media Player และ Internet Explorer 6

🛡️

Server 2003 / Vista

เน้นการปรับปรุงความปลอดภัย มี UAC รองรับการแสดงผล 3D และระบบ 32/64 บิต

🪟

Windows 7

มี Aero Glass, Super Bar, Snipping Tool, Libraries, Aero Snap และ Windows Media Player 12

🟦

Windows 8 / 8.1

ออกแบบให้เหมาะกับจอสัมผัส มี Start Screen, Live Tiles, Charms Bar, Ribbon, Hyper-V และ Windows To Go

🌙

Windows 10

Start Menu แบบผสม, Snap Assist, Night Light และ Task View สำหรับ Multiple Desktops

✨

Windows 11

Start และ Taskbar อยู่กึ่งกลาง หน้าต่างมุมมน Snap Layouts, Widgets, Auto HDR, DirectStorage, Copilot, เครื่องมือ AI และคุณสมบัติการช่วยการเข้าถึง
