02 · WINDOWS 10 CONCEPT

แนวคิดสำคัญของ
Windows 10

Windows 10 ถูกพัฒนาต่อยอดจาก Windows 8 โดยออกแบบให้ใช้งานได้กับคอมพิวเตอร์ตั้งโต๊ะ แท็บเล็ต สมาร์ทโฟน และอุปกรณ์ฝังตัว

💻

รองรับหลายอุปกรณ์

สามารถใช้งานได้บนอุปกรณ์หลายรูปแบบ

📱

แอปเดียวหลายอุปกรณ์

แนวคิดการใช้งานแอปพลิเคชันร่วมกันในอุปกรณ์ต่างชนิด

🎯

เรียนรู้การใช้งาน

รู้จักส่วนประกอบเดสก์ท็อปและการใช้งานระบบเบื้องต้น

🧩

เลือกใช้โปรแกรม

สามารถเลือกแอปพลิเคชันให้เหมาะกับงานได้

03 · DESKTOP FEATURES

ส่วนประกอบของ
เดสก์ท็อป

Windows 10 มีเครื่องมือที่ช่วยให้ผู้ใช้งานจัดการหน้าต่าง และเข้าถึงข้อมูลต่าง ๆ ได้สะดวกมากขึ้น

🖥️

Virtual Desktop

สร้างเดสก์ท็อปเสมือนหลายพื้นที่ เพื่อแยกการทำงานแต่ละประเภท

🗂️

Task View

แสดงหน้าต่างและเดสก์ท็อปที่เปิดใช้งานอยู่

🪟

Snap Assist

ช่วยจัดวางหน้าต่างบนหน้าจอได้สูงสุด 4 หน้าต่าง

🔔

Action Center

ศูนย์รวมการแจ้งเตือนและการตั้งค่าด่วน

🌷

Start Menu

เมนูเริ่มต้นสำหรับเปิดโปรแกรมและเข้าถึงการตั้งค่า

📱

Start Screen

หน้าจอเริ่มต้นที่แสดงแอปพลิเคชันในรูปแบบไทล์

04 · START MENU

เมนูคลิกขวาที่
ปุ่ม Start

เมนูทางลัดที่ช่วยให้เข้าถึงเครื่องมือและการตั้งค่าของระบบได้รวดเร็ว

ชื่อเมนูหน้าที่การทำงาน
Apps and Featuresจัดการแอปพลิเคชัน
Mobility Centerจัดการการตั้งค่าการใช้งานแบบเคลื่อนที่
Power Optionsตั้งค่าการใช้พลังงาน
Event Viewerดูบันทึกเหตุการณ์ของระบบ
Systemดูข้อมูลระบบคอมพิวเตอร์
Device Managerจัดการอุปกรณ์ฮาร์ดแวร์
Network Connectionsจัดการการเชื่อมต่อเครือข่าย
Disk Managementจัดการดิสก์และพาร์ทิชัน
Computer Managementรวมเครื่องมือจัดการคอมพิวเตอร์
Windows PowerShellเปิดเครื่องมือคำสั่งของ Windows
Task Managerจัดการโปรแกรมที่กำลังทำงาน
Settingsเปิดหน้าการตั้งค่า
File Explorerจัดการไฟล์และโฟลเดอร์
Searchค้นหาไฟล์และโปรแกรม
Shut down or sign outปิดเครื่องหรือออกจากระบบ
Desktopแสดงหน้าเดสก์ท็อป

06 · WINDOWS STORE

แอปพลิเคชันจาก
Windows Store

แอปพลิเคชันมีรูปแบบการใช้งานและค่าใช้จ่ายที่แตกต่างกัน

🆓

Free App

แอปพลิเคชันที่ดาวน์โหลดและใช้งานได้โดยไม่เสียค่าใช้จ่าย

💳

Paid App

แอปพลิเคชันที่ต้องชำระเงินตามเงื่อนไขการใช้งาน

⏰

Free Trial

แอปพลิเคชันที่เปิดให้ทดลองใช้งานในช่วงเวลาที่กำหนด

📄

Drawboard PDF

แอปพลิเคชันสำหรับเปิดดูและเขียนคำอธิบายประกอบไฟล์ PDF

✏️

Drawboard PDF

ใช้สำหรับดูและเขียนคำอธิบายประกอบไฟล์ PDF รองรับการใช้งานร่วมกับปากกา Stylus หรือการสัมผัสหน้าจอในรูปแบบ Modern App

07 · LESSON SUMMARY

สรุปท้ายบทเรียน

สิ่งสำคัญที่ควรจดจำจากบทเรียน Windows 10

Windows 10 เป็นระบบปฏิบัติการที่พัฒนาต่อยอดจาก Windows 8 รองรับการใช้งานบนอุปกรณ์หลายประเภท มีเครื่องมือช่วยจัดการหน้าต่าง และเดสก์ท็อป เช่น Virtual Desktop, Task View และ Snap Assist ผู้ใช้สามารถเข้าถึงเครื่องมือผ่านเมนู Start ใช้แป้นพิมพ์ลัด เพื่อเพิ่มความสะดวก และเลือกติดตั้งแอปพลิเคชันจาก Windows Store ได้ตามความต้องการ
